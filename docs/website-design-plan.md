# Operan Public Website — Design & Conversion Plan

**Date:** July 17, 2026
**Primary Goal:** Convert C-suite visitors into qualified executive briefing requests
**Secondary Goals:** Establish credibility, differentiate from competitors, educate on the "departments not tools" concept
**Conversion Funnel:** Website → Executive Briefing Form → Sales call → Enterprise deal ($500K+)

---

## 1. CONVERSION STRATEGY

### 1.1 The Core Conversion Problem

This is not an e-commerce site. Visitors are **C-suite executives** at 1,000+ employee organizations in the GCC. They:
- Have 30 seconds to decide if Operan is worth 30 minutes of their time
- Have seen every "AI platform" pitch possible — skepticism is the default
- Need to feel this is **infrastructure**, not a startup experiment
- Operate in a high-stakes environment where buying wrong is career-ending

### 1.2 Conversion Principles

| Principle | Application |
|-----------|-------------|
| **Every element must earn its keep** | No decoration. Every visual, word, and interaction must either build credibility, reduce risk, or clarify value. |
| **Credibility before action** | Executives don't "sign up." They need to trust Operan exists, is mature, and is sovereign before they click a CTA. |
| **Reduce perceived risk** | "No sales pitch" framing. "Deployable air-gapped" reassurance. "Saudi government trusted" signal. |
| **One conversion path** | Every page has exactly ONE CTA action. No distractions. No alternate paths. |
| **Depth on demand** | General execs see high-level. Technical execs (CIO/CTO) can find depth without leaving the page. |

### 1.3 Conversion Funnel Architecture

```
Homepage
  │
  ├─→ "See How It Works" → Platforms Page → CTA → Briefing
  ├─→ "Learn About Human Governance" → Security Page → CTA → Briefing
  ├─→ CTA (hero) → Briefing Page
  │
Departments Page
  │
  ├─→ "See How Departments Empower" → Departments Page (anchor) → CTA → Briefing
  └─→ CTA → Briefing Page
  │
Platform Page
  │
  └─→ CTA → Briefing Page
  │
Industries Page
  │
  └─→ CTA → Briefing Page
  │
Security Page
  │
  ├─→ "Download Security Whitepaper" → gated asset (later)
  └─→ CTA → Briefing Page
  │
Briefing Page (conversion)
  │
  └─→ Form submission → Thank you → "A team member will contact you within 24 hours"
```

### 1.4 Conversion Metrics to Track

| Metric | Target | Rationale |
|--------|--------|-----------|
| **Browsing-to-form rate** | 2–3% | Executive audiences are smaller; 2% is strong |
| **Form completion rate** | 60–70% | 12 fields is moderate friction; optimize after launch |
| **Form abandonment** | Track field by field | Identify if organization size or role fields cause drop-off |
| **Time to first CTA click** | <60 seconds | Measures hero clarity |
| **CTA click-through rate** | 4–6% | Measures CTA effectiveness per page |
| **Secondary CTA usage** | 15–20% | Measures depth-seekers (technical buyers) |

- **12 fields is moderate friction** — but each field serves a qualification purpose
- **Radio buttons (not text)** reduce cognitive load and increase completion rate

- **"No sales pitch" framing** in the hero reduces the perception that filling out the form = a sales call
- **Form submission message:** "Thank you. A team member will contact you within 24 hours." — sets expectations, reduces anxiety

## 5. DESIGN-CONTENT CONVERSION MAP

### 5.1 Every Design Element → Conversion Justification

| Design Element | Conversion Purpose |
|----------------|-------------------|
| **Dark background** | Signals "enterprise infrastructure" not "startup." Builds credibility with C-suite. |
| **Cyan CTA buttons** | High contrast against dark background. Draws eye to the conversion action. |
| **Human-first hero** | "Empower Your Workforce. Replace Broken Work. Not People." — politically safe messaging that aligns with Saudization. |
| **Trust bar with "Human-governed"** | Immediate risk reduction + political validation. Addresses job security concern before the user scrolls. |
| **Metrics strip (Saudization + AI work replacement)** | Political context + operational impact. Two-second scan. Validates the empowerment narrative. |
| **Problem section (broken work, not people)** | Creates urgency. Makes the broken work narrative resonate with GCC operators. Positions Operan as the fix. |
| **Department grid cards with AI/human split** | Visual proof of empowerment. Each card shows AI handles routine, humans handle strategic. |
| **Human-governed autonomy section** | The trust page on the homepage. Addresses job security + sovereignty. Six capability badges = six trust signals. |
| **Final CTA with "No sales pitch"** | Removes the last barrier. Executives fear being "sold to." "No sales pitch" reframes it as educational. |
| **Consistent CTA across all pages** | Reduces decision fatigue. Every page drives to the same action. |
| **Briefing form with radio buttons** | Reduces cognitive load. Radio buttons are faster to complete than text fields. |
| **Form field: "What Work Do You Want AI to Handle?"** | NEW. Qualifies the lead AND helps sales tailor the briefing to specific pain points. |
| **Form field: "Evaluating Against"** | Qualifies the lead AND tells sales which competitive frame to use. |
| **24-hour contact promise** | Reduces abandonment anxiety. "They'll call me within 24 hours" is manageable. |
| **Arabic toggle (phase 2)** | Signals Arabic-first commitment. Even just a toggle signals respect for the market. |

### 5.2 Visual Hierarchy (What the Eye Sees First)

```
1. HERO CTA BUTTON (cyan, high contrast) — conversion action
2. HERO H1 (56px, white) — value proposition
3. TRUST BAR (small text below CTAs) — credibility
4. METRICS (large numbers, cyan) — social proof
5. DEPARTMENT CARDS — product depth
6. SECONDARY CTA — curiosity-driven engagement
7. FOOTER — information only
```

### 5.3 Anti-Patterns (What NOT to Do)

| Anti-Pattern | Why It's Wrong |
|-------------|---------------|
| **Gradient backgrounds** | Reads as "startup SaaS," not enterprise infrastructure. |
| **Stock photography** | Undermines credibility. GCC execs recognize generic stock imagery. |
| **Moving hero video** | Slows page load. Distracts from the CTA. |
| **Multiple CTAs on one page** | Creates decision paralysis. One path, one action. |
| **"Sign Up Free" or similar** | Operan is not a freemium product. This language undermines enterprise positioning. |
| **Testimonials from unnamed sources** | "Some company said this" is worse than no testimonial. If no named testimonials exist, omit them. |
| **Animated particle effects** | "Look how techy we are" reads as immature. Enterprise buyers value substance over flash. |
| **Pricing page** | Enterprise infrastructure is priced per-deployment. A pricing page would be misleading and limit negotiation. |
| **Blog/Content section** | This is infrastructure, not a content marketing play. Blog content dilutes the CTA. |
| **Social media icons in footer** | GCC enterprise buyers don't evaluate infrastructure vendors via Twitter. |
| **"AI replaces jobs" messaging** | Politically dangerous in the GCC. Saudization is a national mandate. Framing AI as a replacement for workers will block government procurement and create PR backlash. |
| **"Fully autonomous AI" messaging** | Overpromises and creates fear. Operan is human-governed, not fully autonomous. Messaging must emphasize human oversight and approval gates. |
